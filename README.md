# IronCore Fitness

A two-page gym advertisement website built for the CS103 (Web Designing) mini project using only HTML and CSS.

## Pages

- `index.html` — home page: hero banner, about section, highlights, membership plans with joining steps, gallery and contact details
- `facilities.html` — equipment breakdown table, facilities overview, and branch locations with timings and phone links

## Running locally

Open `index.html` in a browser, or serve the folder with:

    python3 -m http.server

Then visit http://localhost:8000/
